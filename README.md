# Обучение агента вождения с PPO

Учебный проект на Unity и Unity ML-Agents: агент учится вести автомобиль по трассе, избегать стен и проходить чекпоинты. Для обучения используется reinforcement learning с алгоритмом PPO (Proximal Policy Optimization).

## Цель

Агент должен самостоятельно двигаться по трассе: не сталкиваться со стенами, находить следующий чекпоинт, проходить повороты и не останавливаться без причины. Проект проверялся на прямых, L-образных, двойных и более сложных трассах.

## Технологии

- Unity 6 - симуляционная среда
- Unity ML-Agents - обучение агента
- Python и PyTorch - запуск обучения и нейронная сеть
- PPO - алгоритм обучения с подкреплением
- ONNX - экспорт обученной модели для запуска в Unity

## Что получает агент

Агент не видит карту целиком. В наблюдения передаются:

- скорость автомобиля;
- направление движения;
- направление и расстояние до следующего чекпоинта;
- расстояния до стен, измеренные raycast-ами.

Действия агента - управление рулём, газом и торможением.

## Награды

Система наград поощряет прохождение трассы и движение к цели:

- прохождение чекпоинта;
- приближение к следующему чекпоинту;
- движение вперёд;
- штраф за столкновение со стеной;
- небольшой штраф за каждый шаг и движение назад.

Ключевое изменение в проекте - reward за изменение расстояния до чекпоинта. Агент перестал получать награду только за движение вперёд и начал учиться двигаться именно к цели.

## Как развивался проект

1. В первой версии агент знал только расстояния до стен. Я добавил чекпоинты как цели, их направление и расстояние до ближайшей цели. После изменения входных данных обучение запускалось с нуля.
2. Debug-панель показала, что некоторые расстояния всегда равны нулю. Причина была в том, что объектам не назначили нужный Layer: агент фактически не знал об их существовании. После исправления Layer данные стали поступать корректно.
3. Затем были добавлены raycast-ы для определения расстояния до стен. Новые наблюдения снова потребовали обучения с нуля.
4. Агент смог пройти первую трассу с правым и левым поворотами, но не справлялся с более сложными маршрутами. Количество raycast-ов и входных данных увеличили, после чего модель переобучили.
5. Самая показательная версия получила имя **Avel**. До неё была версия **Kane**. Имена стали отсылкой к персонажам, о которых автор проекта вспомнил во время разработки.

## Отладка

Для поиска ошибок использовался отдельный debug-экран. Он показывал текущую трассу, число пройденных чекпоинтов, скорость, расстояние до цели, координаты цели и показания raycast-ов. Благодаря этому удалось обнаружить проблему со слоями объектов и проверить, что агент действительно получает данные о трассе.

## Параметры обучения

Текущая конфигурация находится в [car_config.yaml](car_config.yaml):

- `batch_size`: 512
- `buffer_size`: 10240
- `learning_rate`: 0.0003
- 3 скрытых слоя по 256 нейронов
- `gamma`: 0.99
- `time_horizon`: 128

## Запуск

1. Откройте проект в Unity.
2. Установите зависимости Unity ML-Agents.
3. Для обучения используйте конфигурацию `car_config.yaml`.
4. Экспортированную ONNX-модель подключите к поведению автомобиля в Unity.
